# Archives — anciens guides Atlas (2 novembre 2026)

Cette archive conserve **à l'identique** les 24 anciens JSON de guides remplacés ou retirés, uniquement pour référence et audit. Les fichiers ne sont plus dans `data/encyclopedia/guides/` et **ne sont jamais exportés dans Atlas App**.

- Les 20 guides Dofus actifs utilisent désormais leurs routes Ganymède dans `data/encyclopedia/guides/replacement_drafts/cutovers/`.
- Bonta, Brâkmar et le parcours mixte utilisent les lecteurs locaux Ganymède de la catégorie Alignements.
- Dofoozbz et Dokille n'ont pas de remplacement direct dans l'inventaire 95 sources Ganymède ; leurs anciennes listes de quêtes n'ont pas été conservées dans le catalogue actif.
- Les deux guides optimisés `guide_complet.json` et `dofus_sylvestre.json` n'ont **pas été déplacés ni modifiés**.
- `manifest.json` contient pour chaque fichier son SHA Git blob original. Le déplacement réutilise directement ce blob, sans réécriture des octets.

Ces fichiers ne sont pas une solution de secours du lecteur, et ne doivent jamais être importés par le provider au runtime.

Attention : les 75 autres sources Ganymède conservent des repères factuels locaux, pas encore des consignes détaillées certifiées. Ce rangement n'affirme pas leur complétude.
